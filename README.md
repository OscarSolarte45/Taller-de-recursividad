## Descripción

Este repositorio contiene el desarrollo del taller de recursividad hecho en Java con VScode.

El taller tiene como aplicar el concepto de **recursividad** mediante 14 ejercicios diferentes que permiten resolver problemas utilizando funciones que se llaman a sí mismas.

Los ejercicios desarrollados incluyen:

1. Factorial de un número.
2. Sumatoria hasta un número.
3. Sumatoria de fracciones.
4. Invertir un número entero.
5. Sumar los dígitos de un número.
6. Potencia de un número.
7. Máximo común divisor (M.C.D.) mediante el algoritmo de Euclides.
8. Cociente de una división mediante restas sucesivas.
9. Copiar una cadena.
10. Multiplicación mediante sumas sucesivas.
11. Suma de los elementos de un arreglo.
12. Suma de los elementos de una matriz.
13. Serie de Fibonacci.
14. Función de Ackermann.

## Requisitos

- Java JDK 8 o superior.
- NetBeans o Visual Studio Code.
- Extensión de Java para Visual Studio Code, si se utiliza este IDE.
- Computadora con acceso a una consola o terminal para ingresar los datos solicitados por los ejercicios.
## Cómo ejecutar

Cada ejercicio es independiente y cuenta con su propio método `main`, por lo que puede ejecutarse individualmente.

### NetBeans

1. Abrir el proyecto `Taller-Recursividad`.
2. Ir a `src/Recursividad`.
3. Abrir el archivo `.java` del ejercicio que se desea ejecutar.
4. Presionar **Run File** o **Ejecutar**.
5. Ingresar los datos solicitados en la consola.

### Visual Studio Code

1. Abrir la carpeta `Taller-Recursividad`.
2. Ir a `src/Recursividad`.
3. Abrir el archivo `.java` del ejercicio que se desea ejecutar.
4. Presionar **Run Java** o el botón **Ejecutar**.
5. Ingresar los datos solicitados en la terminal.

No es necesario ejecutar todos los ejercicios al mismo tiempo. Cada archivo puede ejecutarse de forma independiente.
